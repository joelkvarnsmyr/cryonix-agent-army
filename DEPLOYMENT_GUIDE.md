# 🚀 Deployment Guide - Cryonix AI Trading Dashboard

## 📋 Prerequisites Checklist

Before deployment, ensure you have:

- [ ] **Vercel Account** (free tier works)
- [ ] **xAI API Key** for GROK
- [ ] **Binance API Keys** (testnet recommended initially)
- [ ] **Git repository** connected to GitHub
- [ ] **pnpm** installed locally (`npm install -g pnpm`)

⚠️ **CRITICAL WARNING**: This system executes REAL trades on Binance. Always:
- Start with **Binance Testnet** to test everything
- Only move to live trading with **small amounts** you can afford to lose
- Implement all **safety limits** before going live
- Never leave automated trading unmonitored

## 🎯 Step-by-Step Deployment

### Step 1: Setup Vercel Account

1. Visit [vercel.com](https://vercel.com) and sign up
2. Connect your GitHub account
3. Import this repository

### Step 2: Create Vercel Postgres Database

1. In Vercel Dashboard, go to **Storage** tab
2. Click **Create Database**
3. Select **Postgres**
4. Choose a region (closest to your users)
5. Click **Create**
6. Copy all environment variables (you'll need these)

### Step 3: Create Vercel KV (Redis)

1. In **Storage** tab, click **Create Database** again
2. Select **KV** (Redis)
3. Click **Create**
4. Copy environment variables

### Step 4: Configure Environment Variables in Vercel

1. Go to **Project Settings → Environment Variables**
2. Add the following:

```bash
# From Vercel Postgres (auto-populated if database connected)
POSTGRES_URL=
POSTGRES_PRISMA_URL=
POSTGRES_URL_NON_POOLING=
POSTGRES_USER=
POSTGRES_HOST=
POSTGRES_PASSWORD=
POSTGRES_DATABASE=

# From Vercel KV (auto-populated if KV connected)
KV_URL=
KV_REST_API_URL=
KV_REST_API_TOKEN=
KV_REST_API_READ_ONLY_TOKEN=

# xAI GROK API
XAI_API_KEY=xai-your-key-here

# Binance API
BINANCE_API_KEY=your-binance-api-key
BINANCE_API_SECRET=your-binance-api-secret
BINANCE_TESTNET=true  # ⚠️ ALWAYS USE TESTNET FIRST!

# App URL (will be auto-generated by Vercel)
NEXT_PUBLIC_APP_URL=https://your-app.vercel.app
```

3. Set environment for: **Production**, **Preview**, and **Development**

### Step 5: Push Database Schema

```bash
# Local terminal
cd packages/database

# Push schema to Vercel Postgres
pnpm db:push

# Verify with Drizzle Studio (optional)
pnpm db:studio
```

### Step 6: Deploy

```bash
# Option A: Deploy via Git Push
git add .
git commit -m "Initial deployment"
git push origin main

# Vercel will auto-deploy on push!
```

OR

```bash
# Option B: Deploy via Vercel CLI
pnpm add -g vercel
vercel

# Follow prompts:
# - Link to existing project? Yes
# - Which project? [select your project]
# - Deploy? Yes
```

### Step 7: Verify Deployment

1. Visit your Vercel deployment URL
2. Check that dashboard loads
3. Test API endpoints:
   - `https://your-app.vercel.app/api/agents` (should return agent statuses)
   - `https://your-app.vercel.app/api/signals` (should return empty array initially)

## 🔧 Post-Deployment Configuration

### Initialize Agents

Visit your app and open browser console:

```javascript
// Start agents
fetch('/api/agents', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ action: 'start' })
})
.then(r => r.json())
.then(console.log);
```

## 🛡️ Security Best Practices

### Production Checklist

- [ ] **Use Binance Testnet** initially
- [ ] Enable **Binance IP Whitelist** (add Vercel IPs)
- [ ] Set **Withdrawal Restrictions** on Binance
- [ ] Monitor **Error logs** daily
- [ ] Setup **Alerts** for large trades
- [ ] Implement **Rate Limiting** on APIs
- [ ] Enable **2FA** on all services

### Get Vercel IP Addresses

Vercel uses dynamic IPs. For security:

1. Use Vercel's static outbound IPs (Enterprise only)
2. OR use API key restrictions instead of IP whitelist
3. OR deploy on Railway/Render with static IPs
