# scripts/telegram-scraper/

Real-time Telegram channel signal scraper that listens to trading signal channels via Telethon (MTProto user client) and writes parsed signals to Redis and Postgres. Runs as a standalone Docker container.

## Files

| File | Description |
|------|-------------|
| `scraper.py` | Main entry point. Connects to Telegram as a user client via `StringSession`, resolves configured channel usernames to IDs, and registers a `NewMessage` event handler. Incoming messages are parsed, deduplicated (30min window per channel/symbol/action), saved to Postgres `telegram_signals` table, and published to Redis for auto-trade consumption. Builds per-symbol consensus from multiple channels and computes confidence deltas (+5% for 1 channel, +8% for 2, +12% for 3+). Refreshes channel quality metrics from Postgres to Redis every hour. |
| `parser.py` | Multi-format signal parser. Supports three formats: (1) Cornix format with structured entry/SL/TP lines, (2) simple inline format (`BUY SOL @ 88.5, SL 86.8, TP 91.0`), and (3) emoji-driven format (green emoji = buy, red = sell). Normalizes symbols to `SYMBOL/USDC` format across 40+ known trading pairs with alias support. Returns `None` for non-signal messages. |
| `setup_session.py` | One-time session generator. Run locally (not in Docker) to authenticate with Telegram and produce a `TELEGRAM_SESSION` string (Telethon `StringSession`). Requires API ID and API Hash from [my.telegram.org](https://my.telegram.org). |
| `Dockerfile` | Python 3.11 slim image. Installs dependencies and runs `scraper.py`. |
| `requirements.txt` | Python dependencies: telethon 1.37.0, redis 5.2.1, psycopg2-binary 2.9.10, python-dotenv 1.0.1. |

## Redis Keys

| Key | TTL | Description |
|-----|-----|-------------|
| `telegram:signal:{SYMBOL}` | 30min | Per-symbol signal with consensus count and confidence delta. |
| `signals:telegram:active` | 30min | Aggregate list of all active Telegram signals. |
| `telegram:dedup:{channel}:{symbol}:{action}` | 30min | Deduplication guard. |
| `telegram:channel:{id}:quality` | 1h | Channel win rate and signal count cache. |

## Usage

```bash
# One-time: generate session string (run locally, not in Docker)
python3 scripts/telegram-scraper/setup_session.py
# Copy the output TELEGRAM_SESSION=... to your .env file

# Run via Docker Compose
docker compose -f docker-compose.prod.yml up -d telegram-scraper

# View logs
docker logs -f cryonix-telegram-scraper-1

# Run standalone (for development)
cd scripts/telegram-scraper
pip install -r requirements.txt
python3 scraper.py
```

## Environment Variables

| Variable | Description |
|----------|-------------|
| `TELEGRAM_API_ID` | Telegram API ID from [my.telegram.org](https://my.telegram.org). |
| `TELEGRAM_API_HASH` | Telegram API hash from [my.telegram.org](https://my.telegram.org). |
| `TELEGRAM_SESSION` | Telethon `StringSession` string (generated by `setup_session.py`). |
| `TELEGRAM_CHANNELS` | Comma-separated list of channel usernames to monitor. |
| `KV_URL` | Redis connection URL (default: `redis://localhost:6379`). |
| `POSTGRES_URL` | Postgres connection string. |
| `CONFIDENCE_BOOST_ENABLED` | `false` = log only (Phase 1), `true` = active confidence boost (Phase 2). |
