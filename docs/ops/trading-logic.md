# Trading Logic: ETA & Stagnation

This document describes the advanced monitoring logic implemented in Cryonix for predicting Take Profit (TP) arrival times and managing position stagnation.

## 1. Time-to-TP (ETA) Estimation

Cryonix uses a dual-layer approach to predict when a target will be reached.

### Layer A: Source-Level Validation (The Signal)
When a signal is first generated by the Python Engine (`MarketScout`), it calculates a **Market-Validated ETA** based on current volatility and momentum.

*   **Logic:** `(Distance to TP / ATR) * 15 min`.
*   **Intensity Adjustments:**
    *   **Trend Boost:** If ADX > 30, ETA is reduced by 25% (momentum acceleration).
    *   **Volume Boost:** If Volume Ratio > 2.0, ETA is reduced by 20%.
    *   **Stagnation Penalty:** If ADX < 15, ETA is increased by 30% (choppy market).
*   **Purpose:** Provides an "Initial Expectation" based on market physics at the moment of entry.

### Layer B: Live Monitoring (The Trade)
Once a trade is open, the system switches to **Velocity Tracking** to provide real-time updates.

*   **Polling Interval:** Every 30 seconds, the monitor cycle compares the current price with the `lastPrice`.
*   **Velocity Calculation:** `Velocity = (Current Price - Previous Price) / 0.5 minutes`.
*   **Smoothing:** `(New Velocity * 0.2) + (Old Velocity * 0.8)`.
*   **Live ETA:** `Remaining Distance / Velocity = Current Estimated Arrival`.

## 2. Dynamic Stagnation Management

To prevent capital from being locked in "sideways" trades that aren't going anywhere, Cryonix uses a stagnation exit.

### Key Changes (March 2026):
*   **Default Timeout:** Increased from **8 hours to 16 hours**.
*   **Stagnation Threshold:** A position is considered stagnant if it stays within **±1.0%** of entry for the duration of the timeout.
*   **AI Override:** Grok AI can now provide a `stagnation_threshold_hours` per trade. 
    *   *Example:* A high-conviction trend trade might get a **24-48h** window.
    *   *Example:* A volatile scalp might be forced to exit after only **2h** if it hasn't hit TP.

---

## 3. AI Predictive Insights (Grok)

When validating a signal, Grok AI now provides two new data points:
1.  **`estimated_minutes_to_target`**: An initial "Expert Estimate" based on order book depth, X sentiment, and volatility.
2.  **`stagnation_threshold_hours`**: A tailored exit window based on the specific trade setup.

## 4. Telegram Alerts

The system is configured to alert via Telegram when:
*   An ETA is first established.
*   An ETA changes drastically (e.g., from 30 mins to 4 hours) due to a momentum shift.
*   A position enters the "Stagnation Warning" zone (2 hours before auto-exit).
